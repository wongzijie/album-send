# 相册快送 · Android

一个原生安卓应用：选择手机中的照片和视频，将原文件发送到局域网 SMB 共享文件夹。

## 安装与使用

支持 Android 8.0 及以上。安装 `dist/相册快送-debug.apk`；这是用于个人试用的调试签名版本，不是应用商店发布包。

1. 首次打开授权照片和视频。选择“全部照片和视频”后，下次打开会沿用系统授权；系统撤销权限时需重新授权。Android 14 及以上也支持只授权部分内容。
2. 首页按相册、照片或视频筛选。点击勾选；长按一项后拖动可连续勾选或取消，拖到上下边缘会自动滚动。全选只作用于当前筛选结果。
3. 点击右上角“发送”，选择保存的连接，或“搜索局域网”寻找开放 SMB 端口的设备。
4. 填写 IP / 主机名、共享名称、账号和密码。共享名称可留空，连接后列出可见共享；某些服务器禁止列举共享时，请直接填写共享名称。
5. 逐级进入子文件夹，点击“发送到这里”。上一级、刷新和任意深度目录浏览均受服务器权限限制。

首页“文件夹”可提前添加连接，浏览到目标目录后选择“保存此文件夹”；以后直接进入此位置。长按保存的连接可编辑或删除。账号配置采用 Android Keystore 的 AES-GCM 加密后保存在手机，不参与系统备份。没有云端服务。

## 文件传输行为

- 使用 SMB 2 / 3 协商，禁用 SMB 1；实际可用特性以服务器与 jcifs-ng 协商结果为准。
- 不压缩、不转码；发送原文件二进制数据，照片原有 EXIF 也随原文件保留。
- 串行发送，不将整个视频载入内存；通知栏显示进度，可取消。
- 先写 `.album-send-随机值.part` 临时文件，关闭流并校验远端大小后，以不允许覆盖的方式重命名。
- 同名文件自动加 ` (1)`、` (2)` 等后缀；Windows 不支持的字符或保留名称会转换为合法名称。
- 普通失败或取消时清理当前临时文件，继续处理其他文件或停止；未完成项目可点击“重试未完成文件”。
- 文件夹扫描只检查当前网络的本地 IPv4 网段，最多 254 个地址的 TCP 445 端口。跨网段、VPN、IPv6、非标准端口和被防火墙隐藏的设备不在此自动发现范围。可手动填写 IPv4 或主机名；本版默认使用标准端口。

## 开发和验证

项目使用 Java 17、AGP 9.0.1、Gradle 9.2.1、compile SDK 36、target SDK 35。用 Android Studio 打开此目录，安装 SDK 36 及 Build Tools 36.0.0。

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

SDK 路径写在本机 `local.properties`，该文件不应提交到版本管理。构建产物位于 `app/build/outputs/apk/debug/app-debug.apk`。

可运行真实的本机 SMB 集成测试。测试服务器仅绑定 `127.0.0.1:1445`，使用固定的测试账号；退出后清理临时共享目录，不访问用户实际 NAS。

```sh
python3 -m venv /tmp/album-smb-test-env
/tmp/album-smb-test-env/bin/pip install impacket==0.12.0
ALBUM_TEST_PYTHON=/tmp/album-smb-test-env/bin/python tools/test-smb.sh
```

测试覆盖中文与 `+ # %` 路径、多级目录列举、文件写入后的逐字节比对、禁止覆盖同名文件、错误密码，以及文件名安全处理。正常单元测试运行会跳过依赖本机 SMB 服务器的三项测试。测试服务器对 Impacket 0.12 的相关操作句柄继承和错误响应结构作了规范化处理；该处理仅用于本机测试夹具，不修改应用客户端。

## 本版边界

这是可安装的首版原型。构建及集成测试不等于实际手机或实际 NAS 的兼容性验证。真机仍需检查授权、缩略图、长按拖选、设备发现、后台大视频传输、断网重试、存储空间不足和 NAS 权限行为。

后台传输使用前台服务与有界唤醒锁；系统强制停止、强杀进程或 Android 前台服务超时后，不自动恢复上传，也不支持断点续传。强杀可能留下 `.part` 临时文件，可以在目标目录手动删除；原文件和已完成的目标文件不会因此被主动删除。失败重试列表当前保存在进程内，退出进程后需重新选择；最新结果摘要在应用私有目录 `last-transfer.json`。

上传只校验大小，不做整文件哈希，也不保留文件系统修改时间。SMB 加密强制策略、特定企业域认证和所有厂商 NAS 尚未验证。访客访问取决于服务器是否允许匿名认证；需要账号的 Windows / NAS 请填写账号。

实现参考：[Android 媒体授权](https://developer.android.com/about/versions/14/changes/partial-photo-video-access)、[前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types)、[jcifs-ng](https://github.com/AgNO3/jcifs-ng)。
