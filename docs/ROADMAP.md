# 路线图

这些是后续方向，不代表当前版本已支持，也不承诺完成日期。

## 优先：把首版验证扎实

- [ ] 真机验证相册授权、缩略图、长按拖选及边缘滚动。
- [ ] 收集 Windows / Mac / NAS 的读写权限与 SMB 兼容性结果。
- [ ] 验证锁屏、大视频、断网、存储空间不足与取消行为。
- [ ] 准备正式签名与稳定的升级流程。
- [ ] 补充实际设备截图和短操作演示。

## 下一步：让备份更省心

- [ ] 持久化传输队列，进程退出后保留未完成项目。
- [ ] 发送历史与重复文件识别，避免重复副本。
- [ ] 增量备份，只发送上次备份之后新增的内容。
- [ ] 大文件断点续传与更清楚的速度、预计剩余时间显示。
- [ ] 可选文件哈希校验和远端时间信息保留。

## 待评估

- [ ] 按相册或拍摄日期自动组织目标目录。
- [ ] 英文界面及无障碍改进。
- [ ] IPv6、跨网段与非标准 SMB 端口配置。
- [ ] Wi-Fi 条件下的定时 / 自动备份。

项目继续围绕“相册 → 自己的共享存储”这个核心流程。提出建议时，请尽量说明真实使用场景以及现有流程的障碍。
